# The original used NTE103 germanium; the kit ships 2N2219A selected to hFE 70-90 (Q1) and
# 100-130 (Q2). Each transistor footprint has a second base pad (11, 13) for other pinouts.
BOM 1M 100K 33K 8.2K 1.2K 10n 33uF 22uF 2.2uF 1N400X 2N2219Ax2 A500K B2K
io IN=9 OUT=40 V9=8 GND=36
JUMP 5 18    # Q2 collector to the 8.2K: drawn, not picked up

STAGE input input 입력
C 2.2uF 0 1 C1
R 1M 20 21 R1

STAGE core fuzz 퍼즈 코어 (Q1·Q2 직결)
Q 2N2219A c=4 b=10 e=16 Q1
R 33K 6 7 R2
Q 2N2219A c=5 b=12 e=17 Q2
R 8.2K 18 19 R3
R 1.2K 14 15 R4
NC 11 13

STAGE feedback custom 피드백 (Q2 이미터 → Q1 베이스)
R 100K 24 25 R5

STAGE fuzz custom 퍼즈 (Q2 이미터 바이패스)
POT B2K FUZZ 32 31 30
C 22uF 28 26 C2

STAGE output output 출력 (볼륨)
C 10n 23 22 C3
POT A500K VOL 35 34 33

STAGE power power 전원
D 1N400X a=2 k=3 D1
C 33uF 29 27 C4
