# TL072 notch at the top: pins 1-4 down the left (11, 14, 19, 23), 5-8 up the right (24, 20, 15, 12).
BOM 2.2Mx5 100nx2 47uF 10uF 1N400X TL072
io IN=25 OUT=0 V9=9 GND=31
JUMP 25 26   # IN to the 100n input cap

STAGE input input 입력 (바이어스)
R 2.2M 10 22 R1
C 100n 26 18 C1
R 2.2M 8 7 R2
R 2.2M 13 3 R3

STAGE buffer buffer 팔로워 (TL072)
IC TL072 1=11 2=14 3=19 4=23 5=24 6=20 7=15 8=12 U1
R 2.2M 17 30 R4
R 2.2M 28 27 R5

STAGE output output 출력
C 10uF 4 1 C2

STAGE power power 전원
C 47uF 5 2 C3
C 100n 21 29 C4
D 1N400X a=6 k=16 D1
