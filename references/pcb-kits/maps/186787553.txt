# TL072 notch up, both: U1 32=1 38=2 45=3 56=4(V-) / 57=5(GND) 46=6 39=7 33=8; U2 36=1 40=2 49=3(GND) 58=4 / 59=5(GND) 50=6 41=7 37=8.
# ICL7660 notch down: 94=1 90=2 80=3 73=4 / 72=5 79=6 89=7 93=8 (6, 7 copper-less). Pin 5 = -9V (op-amp V-, 47uF 62/60).
# HP = U1A out (n9), BP = U1B out, LP = U2A out. U2B sums HP and LP through 5K/5K dividers (HP+LP = notch) and MID = BP from
# an A10K (lug1 "1" = pad 3 GND), so MID turns the notch into a cut or a boost. SWEEP B10K dual: lug1 "1" on the right
# (84, 97 -> 33R to GND), lug3 82 (HP) / 95 (BP), wipers 83/96 -> 1K -> integrator inputs.
# RESONANCE 1M trimmer: 100 from BP, wiper 102 tied to 101 at U1A +in. Mini toggle SW uses two pads (75 -> 12K, 74 GND):
# fixed closed (12K damping leg in). IN ring 68 -> 69 (220n) and 42 (1M); the extractor merged the cap's far end 55/43 into
# the input net - SPLIT. The B10K dual is written as two knobs (SWEEPA/SWEEPB, BOM counts each gang). 76/78/81 are one pad (100K right end) found three times.
