# Transistor footprint is C-B-E left to right (2.2M from the left pin to the middle pin, 680R on the
# right pin). BLEND uses lug1 and the wiper only - the third hole has no pad, so it is a variable
# resistor in series with the clipping diodes. Diode bands: left one at the top, right one at the
# bottom - an anti-parallel pair to ground.
BOM 2.2M 1M 47K 680R 100nx2 47uF 1N400X 1N4148x2 2N3904 A100K B25K
io IN=22 OUT=5 V9=32 GND=28
JUMP 22 23   # 1M input pulldown: its trace to the IN pad is drawn but not picked up

STAGE input input 입력
R 1M 23 24 R1
C 100n 16 8 C1

STAGE gain gain 공통 이미터 드라이브
Q 2N3904 c=12 b=13 e=14 Q1
R 47K 21 6 R2
R 2.2M 17 18 R3
R 680R 9 25 R4

STAGE clip clipping 다이오드 클리핑 (블렌드)
C 100n 15 7 C2
POT B25K BLEND 4 3 3
D 1N4148 a=19 k=10 D1
D 1N4148 a=11 k=20 D2

STAGE output output 출력 (볼륨)
POT A100K VOL 2 1 0

STAGE power power 전원
D 1N400X a=31 k=30 D3
C 47uF 27 26 C3
