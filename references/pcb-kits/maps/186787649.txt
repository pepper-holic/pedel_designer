# 트랜지스터 실크: MPSA13 위 E(44)·가운데 B·아래 C, 2N5089 위 C(29)·가운데 B(45)·아래 E(53).
# 추출기가 n13 하나로 합친 것을 렌더 확대로 나눔: 9V 잭 쪽(96·79·67, 1N400X 캐소드), 10Ω 뒤 레일(78·73·64·66·89),
# 2N5089 베이스(45·65·85·88 - 1M 컬렉터 귀환과 47Ω). 100n(23-20)의 오른쪽 끝 20은 TONE 3번(4)·로터리 P(33)와 한 선(링 기준 추출(2026-10-31); 4의 선은 23 링을 스칠 뿐 컬렉터와는 안 닿는다).
# 로터리 5접점(P=33, 2=47 LED 쌍, 3=71 2N7000+1N4001, 4=86 1N4148 쌍, 5=101 BAT41 쌍)은 4번(1N4148)으로 고정.
# 나머지 위치의 빨간 LED 2, 2N7000 2, 1N4001 2, BAT41 2는 넷리스트·BOM에서 뺀다(키트 1N4001x3 중 하나는 9V 보호).
# FILTER SW(26-50)는 닫힘으로 고정: 50은 MPSA13 베이스와 이어진 선(렌더 확대), 22n이 4.7n과 병렬이 된다.
# 8-BIT는 실크 "1"이 오른쪽(107), 와이퍼가 1번과 묶인 결합 가변저항. FUZZ C1K는 1번(3)과 와이퍼(2)가 접지 - 이미터 바이패스 가변저항. TONE은 와이퍼가 1번(6)과 묶인 직렬 가변저항.
