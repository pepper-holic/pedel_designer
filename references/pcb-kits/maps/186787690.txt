# Right transistor (19 C, 20 B, 21 E grounded) is the input stage Q1; left one (14 C, 15 B, 16 E) is Q2.
# The pot printed FUZZ sits after the 100n output cap, wiper to OUT: it sets the output level.
BOM 1M 100K 47K 5.6K 1K 820R 100R 100nx2 220p 47uF 10uF 1N400X 2N2222x2 B50K
io IN=18 OUT=3 V9=30 GND=37

STAGE input input 입력
R 1M 28 41 R1
C 100n 7 2 C1

STAGE core fuzz 퍼즈 코어 (Q1·Q2 직결)
Q 2N2222 c=19 b=20 e=21 Q1
C 220p 11 23 C2
R 47K 26 35 R2
Q 2N2222 c=14 b=15 e=16 Q2
R 5.6K 24 32 R3
R 100R 22 33 R4

R 100K 0 12 R5
