# PedalPCB Cream Pie 빌드 문서(docs.pedalpcb.com/project/CreamPieFuzz.pdf 3쪽) 회로도와 연결 전부 일치: 1M·390p·LED 쌍이 B단 6-7번 사이,
#   1uF 출력 캡이 7번 줄에서 내려간다. 톤 망은 기판대로 - 1uF 뒤 노드에서 10K(→4.7n→TONE 3번·47K 접지)와 20K(→150n 접지·2.2K→TONE 1번)가 갈라진다.
# 판매자 메모대로 실크 VOLUME/FLUFF 표기가 바뀌어 있다: 실크 "VOL B100K"(0·1·2)가 FLUFF, "FLUFF B100K"(8·5·6)가 VOLUME.
# RC4558P 홈 위: 42=1 47=2 55=3 64=4 / 65=5 56=6 48=7 43=8. 사각 패드는 전해 +(23·25·38·52·74·35).
# 링 기준 추출(pads.py)로 왼쪽 LED의 둥근 패드와 사각 패드가 따로 잡히고(옛 판독은 50/51/60 조각이 한 패드로 합쳐져 7번·6번이 붙었다),
#   LED 외곽선 '+'에 걸린 조각이 접지로 판정되지 않아 SPLIT·JUMP가 필요 없다.
# 팟 "1": FLUFF는 2(1.5K 쪽, 시계방향이 10uF 쪽 = 퍼즈 증가), TONE은 3(2.2K·150n 저역 쪽, 시계방향이 4.7n 고역), VOLUME은 6(접지).
# 1N400X는 9V(21, 띠)-접지(20) 역전압 보호 션트.
BOM 1Mx3 100K 47K 33Kx3 20K 10Kx2 2.2Kx2 1.5K 10Ω 150n 4.7n 390pF 100pF 100uF 10uFx3 1uFx2 1N400X LED-REDx4 RC4558P B100Kx2 B10K
