# TL074 notch on the left: pins 1-7 along the bottom row 81..87, 8-14 back along the top row 67..61. Pin 4 (84) V+, pin 11 (64) GND,
# pins 5/10/12 at Vref (10K/10K 105-106/96-97, 100uF 107-98). A is a unity follower (2-1 tied) on the input; B, C and D are
# inverting stages in the signal order D -> C -> B.
# D: Baxandall bass - input 5.1K -> lug3 (0), wiper -> 5.1K -> -in, lug1 (2, silk "1") -> 5.1K -> out, 47n across each half.
#    The treble half is fixed: 22n -> 22K -> node (1.5K to -in) -> 22K -> 22n -> out.
# C/B: the same mid band on each - pot ends between the previous output (1K, lug3) and this output (1K, lug1 "1") with 100n / 15n
#    across, wiper -> 10n / 1.5n -> -in, 100K in and 100K feedback. CW (toward lug3) boosts on all three.
# 1N400X 91-92 is a reverse-polarity shunt (band at 92 on V+). 108/109, 110/111, 113-115 are duplicate detections of 19/31, 46 and
# the 9V ring 112. Seller notes the original uses an SMD MC3327 quad; the kit ships TL074 (16-pin socket in the list).
