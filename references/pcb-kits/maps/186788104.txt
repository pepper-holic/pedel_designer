# JRC4558D 홈 오른쪽(90도): 49=1 48=2 47=3 46=4(GND) / 64=5 65=6 66=7 67=8(V+). 실크 ⊖ + - ▷ / + - ▽ ⊕와 일치.
# DIP on-off-on: 공통 26(-A). 20 = 빨간 LED 쌍(8·11·18·19), 가운데 = 클리핑 없음, 29 = 1N914 1+2 비대칭. 29(실리콘)로 고정해
# 빨간 LED 2개는 넷리스트와 BOM에서 뺀다(BOM RED LEDx2 제외).
JUMP 26 29

# 팟 라벨이 없어 넷으로 정함: 55/56/57 = DRIVE(56 와이퍼 = 출력, 57 → 10K → -A, 55는 빈 러그), 52/53/54 = VOLUME(54가 Vref),
# 96/97/98 = TONE(-B/와이퍼/+B, 와이퍼 → 220n → 220R). 값은 부품표 A1M/B100K/W20K. DRIVE 1번 = 57(시계방향 = 귀환 저항 증가),
# VOLUME 1번 = 54, TONE 1번 = 98(+B 쪽, 시계방향 = -B 쪽 = 밝게; 방향 추정).
NC 55
