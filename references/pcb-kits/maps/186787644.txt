# Variant of NEW Cat (186787642, same "ALL RAT" board, same render and parts list). The variant parts come from the
# seller's variant table on every ALL RAT page (img_03: C13, R4, R10, R15, R16, D1/D2 per CAT / CAT II / TURBO /
# VINTAGE / DIRTY); the rest of the map is NEW Cat's, connection for connection. The parts pack ships LM308 for every
# variant, so the op-amp stays LM308. R4 is the + in bias resistor, R10 the JFET gate resistor, R15 the 10K pulldown
# on the C13 side of VOLUME (pads 18-34), R16 a 9V -> gate bias resistor (pads 15-31, Turbo only).
# TURBO column: C13 10uF, R4 2.2M, R10 2.2M, R15 10K, R16 2.2M, D1/D2 red LEDs. The page says to bridge the selector
# 2-3 for the Turbo: pad 56 ("2", the clipping node) to 72 ("3", the LED common), so the axial D1/D2 pads (57-59, 96, 97)
# stay empty and the two round LED footprints (73/74 and 85/86) clip. They sit anti-parallel: D1 square pad 73 on the
# LED common with 74 on ground; D2 square pad 86 is the ground side (an isolated dark ground pad in the extraction, joined
# to GND in io) and 85 on the common. The page title says Turbo Cat while its text was copied from the Dirty Cat page.
# The original Turbo RAT uses an OP07; this kit ships LM308.
