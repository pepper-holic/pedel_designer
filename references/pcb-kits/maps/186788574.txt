# DIP 듀얼 on-off-on = NORM/BRIGHT/LINK 토글: 가운데 줄 67·68이 접지 공통. 윗줄 62(22K‖1M 위쪽)·63(47uF)이 한 위치,
#   아랫줄 77·78(브리지드-T 가운데 n27)이 반대 위치, 가운데는 둘 다 열림. 모든 부품이 쓰이는 윗줄 위치로 고정(JUMP 62 67, 63 68):
#   2단 소스 1K에 47uF 바이패스가 들어가고 브리지드-T 가운데가 22K‖1M로 접지된다. 어느 이름의 모드인지는 미확인. 54·80은 DIP 양끝 빈 패드.
# 97-98 캡은 실크 "100p"(부품표에 빠짐) - BLACK AMP 65의 같은 자리는 10p.
# 팟 이름: 실크 없음. 상품 사진 = 윗줄 BASS·MID·TREBLE, 아랫줄 GAIN·VOLUME. 기판은 케이스 기준 좌우 거울상
#   (아랫줄 왼쪽 109-111이 접지 끝·와이퍼→220n→폴로어 = VOLUME, 오른쪽 112-114가 10K 뒤 분압→게이트 = GAIN).
#   추측: 33-35 TREBLE(와이퍼 34→3단 게이트, 2.2n 끝), 36-38 MID(38 접지, 와이퍼 37에 220n 주입), 39-41 BASS(39=40 가변저항).
# 팟 값(부품표 A500K, A100Kx2, B25K, B2K): VOLUME A500K, GAIN A100K, MID B2K(펜더 10K 미드의 축소값).
#   후보: TREBLE/BASS = A100K/B25K 또는 B25K/A100K, 지금은 TREBLE A100K·BASS B25K.
