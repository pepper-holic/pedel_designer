# SMD J201 legs are drawn as cyan runs from the black SOT-23 bodies to the next pad; the extractor gives them no pads, so each

# Supply: 9V 57 -> 1N400X 68-86 -> 9V (100uF 89-90) -> ICL7660 (87=1 93=2 98=3 103=4 / 88=8 94=7 99=6 104=5) doubler with 1N400X
# 77-78 / 69-70, 100uF 97-102 and 10uF 71-72, then 47R 66-67 to the high rail n0 (seller: about 15V there). The pump, its two
# diodes, two caps and the 47R are not simulated and left out of the BOM line; n0 is an ideal 15V rail (RAIL 67 15).
# Trimmers 100K x4 (seller: set every J201 drain to about 7.4V): each has two lugs on n0, so it is a variable resistor from the
# high rail to the drain. A pot is simulated at its midpoint, so each is written as the fixed value that puts its drain near 7.4V
# (TRIM1..4) and the BOM line carries those values in place of the 100K trims.
# Angle pots, no silk names; parts list B1M x2, A1M, A100K, roles from the nets:
#   73-84-95: 680p from the stack input on 95, 10n to ground on 73, wiper 84 to the DRIVE pot -> TREBLE B1M (lug1 73).
#   74-85-96: 100K from the stack input on 74, wiper 85 with 1n from 74 and 22n to 96, 68K from 96 to ground -> BASS B1M (lug1 96).
#   51-52-53: stack output on 51, wiper 52 = Q2's gate, 53 -> 27K to ground -> DRIVE A1M.  54-55-56: wiper 55 = OUT -> VOLUME A100K.
