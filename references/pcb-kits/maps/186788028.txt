# TL071 notch up: 1=21 (NC), 2=28, 3=34, 4=42, 5=43 (NC), 6=35 (out), 7=29 (V+), 8=22 (NC).
# DRIVE lugs 0 and 1 (wiper) are joined on the board: a variable resistor from lug 2. The pot's
# connection to the output (lug 2 = pin 6) is not visible in the render; without it the stage has
# no feedback, so it is taken as present (JUMP 2 35).
BOM 1Mx2 330K 47K 10Kx2 8.2K 6.8K 47R 100n 47nx2 100p 22uFx2 10uF 1N400X LED-REDx2 TL071 A1M A250K A50K
io IN=52 OUT=18 V9=49 GND=39
JUMP 0 1
JUMP 2 35
NC 21 43 22 3   # offset-null and NC pins, unused treble lug
