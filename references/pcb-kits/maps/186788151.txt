BOM 1M 150K 100K 10Kx8 1.8K 1Kx3 220R 100Rx2 1000n 470n 220nx3 100n 100p 82p 47uFx2 22uF 2.2uF 1N400X LED-RED TL072 BC550Cx2 A1M B25Kx2 B100K
# '+' 접지 패드 중 31(100p 아래)·95(220n 오른쪽)는 추출기가 못 잡았다.
io IN=8 OUT=9 V9=2 GND=96,31,95
# TL072 홈 위: 56=1 60=2 74=3 78=4(GND) / 79=5 75=6 61=7 57=8(V+). 실크 ⊕/▷/-/+ 표시와 일치.
# 팟 라벨이 없어 상품 사진(노브: 위 Vol·Drive, 아래 Tone·Accent, 토글 Jazz/Rock)으로 정함. 기판은 케이스 앞면과 좌우가 뒤집혀
# 위 줄 45-47 = DRIVE, 48-50 = VOL, 아래 63/80/92 = ACCENT, 64/81/93 = TONE. 넷 역할도 맞다(DRIVE는 A단 귀환, VOL은 Vref로 가는 분압,
# ACCENT는 B단 귀환 가변저항, TONE 와이퍼는 100n+220R 접지 - Zendrive의 VOICE/TONE 구조). 값: A1M=DRIVE, B100K=VOL, B25K=TONE·ACCENT.
# 1번 러그: VOL은 50(Vref)이 1번(시계방향 = 커짐), DRIVE도 같은 쪽 47이 1번(시계방향 = 귀환 저항 증가), ACCENT는 63(-B)을 1번으로 둔
# 가변저항(92는 동박 없는 빈 러그), TONE은 같은 위치 64(-B)를 1번. ACCENT·TONE의 방향은 추정.
NC 92
# Jazz/Rock DIP on-on: 공통 43, 51(GND) 쪽이 470n(35-36)을 출력단 100R 뒤에 접지로 거는 Jazz, 34(동박 없음)가 Rock.
# Rock으로 고정: 470n(35-36)은 넷리스트·BOM에서 뺀다(BOM 470nx2 → x1).
NC 34 43 51 35 36
