# SMD J201 legs are the virtual pads from the SMD pass: Q1 S 85 / G 86 / D 87, Q2 S 79 / G 81 / D 80, Q3 D 82 / G 84 / S 83.
# Trimmers 50K: the side pad 9 / 12 shows no copper, so each is a variable resistor from V+ (2 / 5) to the T.P node (10-11 / 13-14)
# feeding the 10K drain resistor. Seller: set the drain to about 4V. A pot is simulated at its midpoint (25K), which pulls the J201
# drain below ground, so each trimmer is written as the fixed 8.2K that gives 3.9V at the drain (TRIM1 / TRIM2); the BOM line
# carries 8.2Kx2 in place of the parts list's 50K trim x2.
# Angle pots, no silk names; values from the parts list (B2M, A1M, A250K, A100K), roles from the nets:
#   34-35-36: wiper 35 = OUT, 36 ground -> VOLUME A100K.
#   31-32-33: Q1's signal (n11) on 31, wiper 32 = Q2's gate, 33 ground; 470p+470K from 31 to the wiper -> GAIN A1M (bright divider).
#   48(no copper)-59-68: a series variable resistor 59-68 between the 470K and the GAIN pot, bypassed by 240p -> BASS B2M
#     (guess: less resistance clockwise passes more lows; the other candidate name is "FAT"/"BODY").
#   49(no copper)-60-69: 22n from Q3's drain to 69, wiper 60 on ground -> TONE A250K (treble shunt, brighter clockwise).
# Parts list says 10uF x1 but the board has two source bypass caps (17-18, 24-25); both kept. 1N400X 6-26 is a reverse shunt.
