# 회로도 배치·배선 개선 계획 (2026-10-27)

자동 배치된 회로도가 전기적으로는 맞지만 **회로도로 읽히지 않는** 문제를 고친다. 기준 사례는
"TS9 스타일 오버드라이브 (비이상적 Op-Amp)" 프리셋(`preset.layout` 없음 → `arrangeParts` +
`rewireNets` 경로).

## 0. 현재 상태 (실측)

TS9 프리셋을 불러온 직후의 데이터:

| 부품 | 위치 | 회전 |
|---|---|---|
| V1 | (100,400) | 0 |
| Rin | (260,400) | 0 |
| D1 | (420,400) | 0 |
| DRIVE | (420,250) | 0 |
| D2 | (420,100) | 0 |
| U1 | (420,550) | 0 |

- 노드 n2(`Rin:b, D1:anode, DRIVE:a, U1:inMinus, D2:cathode`), n3(`DRIVE:wiper, DRIVE:b, D1:cathode, D2:anode, U1:out`)
  모두 고리 없는 트리(5단자/4선) — **연결은 정상, 문제는 그리기**.
- 관련 코드: `src/editor/layout/arrange.ts`(배치), `layout/spine.ts`·`layered.ts`(그룹 안 행/열),
  `layout/rewire.ts`(Prim 최단 트리), `routing/astar.ts`·`routing/wirePolylines.ts`(선 경로),
  `layout/metrics.ts`(교차·길이·몸통 관통), 품질 회귀 테스트 `tests/editor/layout.test.ts`
  ("layout quality across every preset": bodyHits 0, 프리셋당 교차 ≤ 8, 합계 ≤ 30).

## 1. 문제 → 원인

| # | 보이는 문제 | 원인 |
|---|---|---|
| P1 | D2 위에 네모 고리, 왼쪽 세로선이 두 줄 | 역병렬 다이오드 D2가 D1과 같은 방향(0°) — 캐소드가 오른쪽인데 왼쪽 노드(n2)에 붙어야 해서 선이 몸통을 돌아감. **배치가 부품 방향(회전/반전)을 고르지 않음** |
| P2 | U1 왼쪽에서 −/+ 선이 엇갈림 | op-amp 기호는 + 위·− 아래인데 피드백(−)은 위, 접지(+)는 아래. **상하 반전(mirror) 개념이 없음** (`Rotation`만 있음) |
| P3 | 신호가 아래→위로 흐르고 out이 중간에 있음 | `spineLayout`이 op-amp를 척추에서 밀어내고 다이오드·포트를 한 열에 세로로 쌓음. op-amp 증폭단의 관용 배치를 모름 |
| P4 | 같은 노드의 선이 나란히 두 줄, 접속점 없는 교차 | `rewireNets`가 단자쌍 선분 트리를 만들고 `routeWires`가 선마다 따로 경로 탐색 → 공통 줄기(trunk)가 없음. 접속점은 단자에만 찍힘 |
| P5 | 와이퍼 선이 "DRIVE" 글자를 지나감, IN/OUT 포트 표시·프로브 꼬리표가 겹침 | 이름표·값·포트 표시·프로브 꼬리표 위치가 고정 오프셋, 충돌 검사 없음 |

## 2. 단계

### L1. 부품 방향 최적화 (P1, P2 일부)

- `PartInstance`에 `mirror?: boolean` 추가(세로축 기준 상하 반전; op-amp·트랜지스터·가변저항에 의미).
  `geometry.terminalPosition`/`rotateOffset`과 `symbols.tsx` 렌더, PCB `boardNetlist`(핀 번호는 불변)에 반영.
  저장 포맷은 선택 필드라 스키마 버전 유지(없으면 false).
- 인스펙터·단축키: `R` 회전 옆에 `M` 반전, 인스펙터 "반전" 버튼.
- `arrange.ts` 끝에 **방향 패스**: 고정(pinned)되지 않은 각 부품에 대해 후보 방향
  (2단자: 0°/180°, op-amp/BJT/JFET/팟: ×mirror)을 두고, 그 부품에 닿는 선들의 Manhattan 길이 +
  교차 수(가중)를 최소화하는 방향을 탐욕적으로 고른다(2~3회 반복, 결정적 순서).
- 수용 기준: TS9에서 D2가 180°가 되어 n2·n3에 각자 한 줄로 붙음, U1 −가 위(피드백 쪽).

### L2. op-amp 증폭단 템플릿 (P3)

- 블록/그룹 안에서 op-amp 증폭단을 인식: op-amp 하나 + 출력↔반전입력 사이 피드백 소자 집합
  (`out`과 `inMinus` 두 노드에만 닿는 부품) + 입력 소자(`inMinus` 또는 `inPlus`에 닿는 직렬 소자).
- 관용 배치를 직접 계산:
  - 신호 행: 입력 소자 → op-amp(−가 위로 반전) → 출력 쪽 다음 부품, 왼쪽→오른쪽.
  - 피드백 소자는 op-amp 위로 **가로 사다리**: 각 소자를 수평으로, 행 간격 일정, 왼쪽 끝은 − 노드
    세로 레일 하나, 오른쪽 끝은 out 세로 레일 하나.
  - 비반전 입력은 아래(접지·바이어스 쪽).
- 비반전 증폭(TS808류: 입력이 `inPlus`, 피드백+접지 저항이 `inMinus`)도 같은 틀 — 접지 다리는 아래.
- 인식 안 되는 그룹은 기존 `spineLayout` 그대로.
- 수용 기준: TS9·Op-Amp 드라이브류 프리셋이 교과서식 반전/비반전 증폭기 모양, 블록 영역 높이 감소.

### L3. 노드 단위 배선 (P4)

- 선 데이터(`Wire`)는 그대로 두고 **그리기만** 바꾼다: 같은 노드의 선들을 모아 공통 줄기를 갖는
  직교 Steiner 트리(레일)로 경로를 만든다 — 단자들이 한 세로/가로선에 모일 수 있으면 레일 하나 +
  짧은 가지.
- 병렬 소자(두 끝 노드가 같은 소자들)는 L2 사다리와 같은 2-레일로 그림.
- T 연결점마다 접속점(dot)을 찍고, 네 갈래 교차는 레일을 한 칸 밀어 피함. 서로 다른 노드의
  교차는 점 없이(필요하면 작은 hop 없이 그대로) — 규칙이 일관되면 됨.
- `routeWires`에 노드 그룹 입력 추가, 기존 단일 선 라우팅은 사용자 경유점(waypoints) 선에만.
- `metrics.ts`에 "같은 노드 평행 중복 선분" 지표 추가.
- 수용 기준: TS9에서 n2·n3가 각각 레일 하나, 중복 평행선 0.

### L4. 이름표 충돌 회피 (P5)

- 이름표(부품 id), 값, 포트 표시(IN/OUT), 프로브 꼬리표, DC 전압 표시의 후보 위치(위/아래/좌/우,
  2~3단 오프셋)를 두고 선분·부품 몸통·다른 이름표와 겹치지 않는 첫 후보를 고르는 탐욕 배치
  (`layout/labels.ts`, 순수 함수 + 테스트).
- 팟 와이퍼 선은 이름표 반대쪽으로.
- 수용 기준: 23개 프리셋 전체에서 이름표–선, 이름표–이름표 겹침 0(테스트로 측정).

- 단위: `tests/editor/layout.test.ts`에 방향 패스·증폭단 인식·레일 경로·이름표 배치 테스트,
  그리고 "전기적으로 동일"(AC 응답 비교) 회귀를 L1~L3 각각에 적용.
- 전 프리셋 품질 테스트 강화: bodyHits 0 유지, 교차 합계 ≤ 30 → 목표 ≤ 15,
  중복 평행선 0, 이름표 겹침 0.
- 스크린샷: TS9, Big Muff, RAT, Klon, 기타 배선 프리셋을 1440×900에서 전/후 비교.

## 4. 순서와 범위

L1 → L2 → L3 → L4 순서(앞 단계가 뒤 단계의 입력을 단순하게 만든다). 각 단계 끝에 테스트·스크린샷·커밋.
사용자가 직접 놓은(pinned) 부품과 경유점이 있는 선은 어느 단계에서도 건드리지 않는다.
`preset.layout`이 손으로 지정된 프리셋은 배치는 유지하되 L3·L4(그리기)는 적용된다.

## 5. 진행 상황 (2026-10-29)

L1~L4가 들어간 뒤에도 TS9 등에서 "한 번 꺾기" 배선이 다른 부품 몸통·다른 노드의 선 위를 그대로
지나가고, 프로브 깃발·포트 표시가 충돌 검사 없이 찍히던 문제를 다음과 같이 마무리했다.

- **후보 기반 라우터** (`routing/netRouter.ts`, `routing/routeCandidates.ts`): 선마다 직선·L·Z·
  (필요할 때만) 4번 꺾는 우회의 후보를 열거하고, 몸통 관통(1000)·다른 노드 선과 겹침(2000)·다른
  노드 핀 통과(600)·교차(60)·꺾임(30)·핀에서 바로 꺾기(80)·길이로 점수를 매겨 고른다. 격자 탐색이
  아니라 손으로 그린 형태 몇 가지 중에서만 고르므로 계단 모양이 나오지 않고 결정적이다. 짧은 선부터
  두 번 돌며, 사용자 경유점이 있는 선은 고정 장애물로만 쓴다. 드래그 시작 때 얼리는 모양도 이 경로.
- **Op-Amp 사다리** (`layout/opampStage.ts`): 피드백 소자를 모두 op-amp 열의 가로 가로대(rung)
  하나의 사다리로 놓고(첫 가로대 120px, 피치 70px), 반전단은 op-amp를 상하 반전해 "−"를 위로,
  신호 입력 핀이 정확히 신호 행에 오도록 20px 내린다. 비반전단은 사다리를 아래로, 접지 다리는 왼쪽
  레일 끝에 매단다. 팔로워(out–inMinus 직결)는 "+" 입력으로 본다.
- **분기 배치** (`layout/spine.ts`, `layout/arrange.ts`): 척추는 증폭 소자를 반드시 지나가고, 신호 행
  부품에 매달리는 소자는 붙는 핀 쪽 열(베이스면 앞 열)에, 그 핀의 x에 맞춰(dx) 놓아 선이 핀 위로
  곧장 떨어진다. 방향 패스는 재배선된 최근접 트리로 점수를 매기고, 신호 행의 2단자 소자는 축을 지키며,
  분기 소자는 세로를 선호(가로 +250)하고, 전압원은 접지된 핀이 아래로 오게 세운다. 접지 기호는 섬기는
  단자 바로 아래(+40)에 건다.
- **이름표** (`layout/labels.ts`, `layout/partLabels.ts`, `layout/probeLabels.ts`): 프로브 깃발·DC
  표시도 같은 탐욕 배치로 들어가고(대각선 후보, 리더선이 선을 가로지르지 않는 자리 우선), 부품 기호
  상자 가장자리에서 거리를 재며, 가까운 단을 방향보다 먼저 본다. 접지 기호·블록 제목·포트 표시가
  장애물에 포함된다.
- **품질 테스트** (`tests/editor/routeQuality.test.ts`): 23개 프리셋 전부에서 몸통 관통 0, 다른 노드
  핀 통과 0, 다른 노드 선 겹침 0, 이름표–장애물 겹침 0, 이름표끼리 겹침 0, 깃발 겹침 0을 강제하고
  교차 합계 ≤ 24(현재 22, 시작 시 52).
