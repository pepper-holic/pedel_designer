# UI/UX 재설계 — 사용 흐름 중심 (2026-10-27)

기능은 그대로 두고, **무엇을 어디서 하는지**와 **다음에 뭘 하면 되는지**를 다시 짠다.

## 1. 지금 화면의 문제 (1440×900에서 실측)

| 문제 | 증상 |
|---|---|
| 캔버스가 좁다 | 하단 분석 도크가 가운데 열의 절반을 차지 → TS9를 불러오면 41% 배율, 부품 글씨가 안 읽힌다 |
| 소리 조작이 흩어져 있다 | 입력 신호·레벨·시뮬레이션·실시간 재생·미리듣기·출력 노드가 오른쪽 사이드바 맨 아래. 부품을 하나 선택하면 인스펙터가 길어져 화면 밖으로 밀린다 |
| 다음 단계가 안 보인다 | 듣기(연주)는 툴바의 작은 토글, 분석·제작은 하단 탭 11개 사이에 섞여 있다. 프리셋을 불러온 사람이 "이제 뭘 하지?" |
| 설명이 본문을 잡아먹는다 | 캔버스 위 단축키 22개가 문단으로 늘 보인다 |
| 첫 화면이 빈약하다 | 빈 격자 + 한 줄 안내. 시작 방법(프리셋/블록/부품/파일)이 한눈에 안 보인다 |
| 상태 알림이 세 군데 | 사이드바 상태문, 연주 뷰 상태문, 하단 "준비됨"(항상 고정) |
| 날 것의 컨트롤 | 브라우저 기본 파일 선택("Choose File"), 모델 파라미터(Is=4.352e-9)가 인스펙터 맨 위를 차지 |

## 2. 원칙

1. **작업 단계가 곧 화면**: 설계 → 연주 → 분석 → 제작. 상단에 단계 탭(1–4 키)으로 항상 보이고, 각 단계는 그 일에 맞는 배치를 가진다.
2. **소리는 어디서나 같은 자리**: 하단 트랜스포트 바 하나(입력 신호·레벨·▶ 실시간·미리듣기·듣는 지점·캐비닛·상태). 단계를 바꿔도 그대로.
3. **캔버스 우선**: 설계 단계에서 회로도가 가운데를 거의 다 쓴다. 분석 도크는 접힌 상태로 시작(검사·응답·노브 스윕만).
4. **선택하면 그것만**: 오른쪽은 선택한 것의 인스펙터. 아무것도 선택하지 않으면 "회로 요약"(검사 결과, 측정 지점, 다음 단계 안내).
5. **도움말은 필요할 때**: 단축키는 `?` 오버레이로. 툴팁은 짧게.
6. **비어 있을 땐 길을 보여준다**: 빈 회로엔 시작 카드, 회로가 없는 단계엔 "설계로 가기".

## 3. 화면 구성

```
┌ 앱 바 ─────────────────────────────────────────────────────────────────────────────┐
│ ■ PEDAL DESIGNER  TS9 스타일 오버드라이브 · 자동 저장됨 │ 1 설계 2 연주 3 분석 4 제작 │ ↶ ↷ 파일▾ ? │
├────────────────────────────────────────────────────────────────────────────────────┤
│                          (단계별 작업 영역)                                          │
├ 트랜스포트 ─────────────────────────────────────────────────────────────────────────┤
│ 입력 [코드▾] 레벨 ━━●━ 0.50V │ ▶ 실시간 재생 · 부하 17% │ ☑ 노브 미리듣기 │ 듣는 지점 [out▾] │ 캐비닛 [끔▾] │ 상태 │
└────────────────────────────────────────────────────────────────────────────────────┘
```

- **1 설계**: 왼쪽 라이브러리(프리셋 / 블록 / 부품 탭 + 검색) · 가운데 캔버스(도구 줄은 캔버스 머리에) · 오른쪽 인스펙터/회로 요약 · 아래 접히는 빠른 분석(검사·주파수 응답·노브 스윕).
- **2 연주**: 페달 전면판 + 응답 + RTA. 입력 관련 조작은 트랜스포트로 이동(중복 제거).
- **3 분석**: 왼쪽 회로도(프로브 찍기용) · 오른쪽 큰 분석 영역(주파수 응답·파형·스펙트럼·노브 스윕·임피던스·THD·부품 공차·페달 체인). 머리에 "▶ 시뮬레이션 실행"과 결과가 회로보다 오래됐는지 표시.
- **4 제작**: 왼쪽 단계 목록(부품 목록 → KiCad → 스트립보드 → PCB → 인클로저) · 오른쪽 전체 높이 작업 영역(보드 그림이 더 이상 도크에 갇히지 않음).

## 4. 흐름

- 처음: 빈 캔버스 위 시작 카드 4장 — "완성된 페달에서" / "블록으로 조립" / "부품부터" / "파일 열기".
- 프리셋을 불러오면: 회로도가 화면에 맞춰지고, 회로 요약에 "다음: 2 연주에서 들어보기 / 3 분석" 안내.
- 어느 단계에서든 ▶ 실시간 재생 → 노브·값을 바꾸면 바로 들림. 분석 단계의 RTA가 같이 움직임.
- 키보드: 1–4 단계 전환, `?` 단축키 도움말, Space 실시간 재생 켜기/끄기(입력 칸 밖에서).
